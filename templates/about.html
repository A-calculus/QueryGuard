All API requests should be made to:

{{ base_url }}

API Endpoint

POST /api/query

Analysis Types

QueryGuard supports different types of analysis, each providing specific insights into the cryptocurrency market:

Market Analysis

Market analysis provides insights into price movements, trading volumes, market capitalization, and overall market trends. This type of analysis helps understand the current state of the market and identify potential opportunities or risks.

{
    "message": "What is the current market sentiment for Bitcoin?",
    "type": "market_analysis"
}
News Analysis

News analysis focuses on recent news articles, social media trends, and public sentiment about specific cryptocurrencies. It helps track market-moving events, regulatory changes, and community sentiment that might affect prices.

{
    "message": "What are the latest news trends for Ethereum?",
    "type": "news_analysis"
}
Signal Analysis

Signal analysis provides technical indicators and trading signals based on price patterns, volume analysis, and other technical metrics. This type of analysis is particularly useful for traders looking for entry and exit points.

{
    "message": "What are the current trading signals for Solana?",
    "type": "signal_analysis"
}

Response Format

The API will respond with a JSON object containing the analysis results:

{
    "status": "success",
    "response": "Detailed analysis response here..."
}

Error Handling

In case of an error, the API will return a JSON object with an error message:

{
    "error": "Error message description"
}

Example Usage with cURL

curl -X POST {{ base_url }}/api/query \
-H "Content-Type: application/json" \
-d '{
    "message": "What is the current market sentiment for Bitcoin?",
    "type": "market_analysis"
}'

Example Usage with Python

import requests
import json

url = "{{ base_url }}/api/query"
data = {
    "message": "What is the current market sentiment for Bitcoin?",
    "type": "market_analysis"
}

response = requests.post(url, json=data)
result = response.json()

if response.status_code == 200:
    print(result["response"])
else:
    print(f"Error: {result['error']}")
